# سوقنا | SOUQNA

متجر أفلييت عربي مبني كصفحة ثابتة على GitHub Pages.

## الملفات
- `index.html` الصفحة الرئيسية.
- `style.css` التصميم المتجاوب.
- `app.js` المنتجات والفلاتر وروابط الأفلييت.
- `about.html` عن سوقنا والإفصاح عن العمولة.
- `privacy.html` سياسة الخصوصية الأولية.
- `terms.html` الشروط الأولية.
- `contact.html` صفحة التواصل.

## إضافة منتج
افتح `app.js` وأضف عنصرًا داخل `products` مع:
- `name`
- `category`
- `categoryName`
- `icon`
- `description`
- `link` (رابط Deeplink من Admitad)

> قبل الإطلاق التجاري، راجع بيانات التواصل، سياسة الخصوصية والشروط، وأكمل جميع المنتجات بروابطها الفعلية وصورها ومعلوماتها الدقيقة.
